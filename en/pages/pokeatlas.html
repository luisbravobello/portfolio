Projects /PokéAtlas

API-powered application / Pokémon exploration

PokéAtlas Turn API data into an easy-to-explore guide.

A reference website for Pokémon fans, bringing together a Pokédex, type relationships, an item catalog and a Kanto guide.

Visit the website (new tab) View repository (new tab)

Project details

Type
API-powered application
Technologies
HTML · CSS · JavaScript · REST API
Hosting
Cloudflare Pages

01 / GOAL

The starting point

An API provides plenty of data, but that data needs context and a clear interface. The challenge was to support searches without overwhelming visitors.

02 / SOLUTION

My approach

I organized the content into sections and added filters, detail cards and pagination. JavaScript handles requests, loading states and errors.

03 / EXPERIENCE

What you can do

  • Browse the Pokédex by region and search by name or number.
  • Filter by type and explore Pokémon detail cards.
  • Browse items with categories and pagination.
  • Get data from PokéAPI with feedback for loading, results and errors.

04 / TAKEAWAY

What I learned

Integrating an API also means handling wait times, incomplete data and errors. The interface should explain what is happening.
