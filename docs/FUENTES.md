## Aplicación

HTML para el contenido; CSS para la presentación; JavaScript para comportamiento. Se usan `header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `footer`, listas y enlaces reales. Los contenedores `div` solo agrupan pares de una lista de descripción cuando el modelo HTML lo permite.

Se aplican jerarquía, proximidad, repetición y contraste; espaciados principales de ocho puntos; foco visible; enlace para saltar al contenido; dimensiones de imágenes; carga diferida de capturas en la portada y animaciones opcionales.

El posicionamiento requiere además publicación, rastreo y contenido relevante. No se inventa la URL del portafolio. Los metadatos dependientes de ella se generan al conocer la dirección real.
